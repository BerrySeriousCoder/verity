# Verity

A document review workspace for source-grounded checks across digital PDFs, spreadsheets, and CSVs.

- [Engineering notebook](docs/README.md)
- [Development setup](project/README.md)
- [Contribution conventions](CONTRIBUTING.md)

Status: repository foundation only. Document ingestion, viewers, agents, and review workflows are not implemented yet. The product checks documents and produces review findings; it does not edit source documents or send external messages. OCR and scanned documents are excluded.
